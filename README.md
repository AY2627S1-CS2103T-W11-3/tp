# AB4 - Contact Manager for NUS Students

This keyboard-first contact manager helps NUS students record and retrieve contacts using remembered relationship context. It uses typed commands as its main interaction method and works offline.

## Features

- Add contacts with names, contact information, tags, and notes.
- List and view saved contacts.
- Find contacts using remembered information across names, contact information, tags, and notes.
- Delete contacts.
- Save and restore contact data locally.

See the [User Guide](docs/UserGuide.md) for usage instructions and the [Developer Guide](docs/DeveloperGuide.md) for technical documentation.
